## 📌 Overview
**Open Georgian** is an open-access, community-driven linguistic database and dictionary interface designed to make Georgian vocabulary and morphological forms easily accessible. It indexes headwords alongside their full declensions and English translations within a fast, clean visual interface.

## ⚙️ Key Features & Architecture
* **Golang Static Site Generator:** Uses a custom Go-based engine to generate fast, light static pages for thousands of lexical entries.
* **Noun & Adjective Paradigm Engine:** Programmatically generates full inflected forms for nouns and adjectives based on Kartvelian morphological rules.
* **Structured UI:** Presents entries, translations, and morphological breakdowns in an intuitive format for language learners and linguists.
